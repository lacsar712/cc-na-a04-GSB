# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

同一灯号的记录按登记时间排成**走低链**（顶栏「走低链」进入），只出文字行不画曲线；某一笔比上一笔低出达到门槛即判走低，单独落一条**走低事件**进**事件册**。门槛由持灯账号在「走低门槛」页设定，写入数据库；事件记下前后两笔主键、当时门槛和差额，以后改门槛，旧事件原文不动。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| keeper | light123456 | 可登记、可设走低门槛 |
| watch | watch123456 | 只读，只能翻走低链和事件册 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. keeper 在明亮的 LH-01（1400 坎德拉）下再登一笔更暗的（如 1300）：顶栏「走低链」里 LH-01 的链上该笔出现走低标记，注明比上一笔少 100 坎德拉；「事件册」同时落一条事件，记下前后两笔主键、当时门槛 50、差额 100。
5. 到「走低门槛」把门槛调大（如 200）：事件册里旧事件的门槛与差额仍是当初的 50 和 100，链上的走低标记也保留；此后再掉 100 坎德拉不再判走低。
6. watch 能翻走低链和事件册，但看不到「登记」「走低门槛」入口，直接提交也会被拒绝。
